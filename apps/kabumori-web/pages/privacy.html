プライバシーポリシー

{{OPERATOR_NAME}}（以下「運営者」）は、スマートフォンアプリ「かぶモリ」（以下「本アプリ」）で取り扱う利用者の情報について、以下のとおり定めます。

1. 取得する情報

情報内容
アカウント情報メールアドレス、認証基盤が発行するユーザーID、パスワード。パスワードは認証基盤でハッシュ化して保存され、運営者が平文を知ることはありません。
登録銘柄の情報利用者が登録した銘柄、保有・監視の区分、保有数量、平均取得単価、現物・信用の区分、売り・買いの区分、目標価格、メモ。
通知に関する情報通知の設定内容、アプリ内に表示する通知の履歴。
プッシュ通知用の情報端末に通知を届けるためのプッシュトークン、端末の機種名（例：「Apple iPhone 15」）。
レポート利用者向けに作成した朝・大引けのレポートの内容。

本アプリは、位置情報、連絡先、写真、広告識別子を取得しません。また、広告配信や行動分析のためのトラッキングを行いません。

2. 利用目的

  • ログイン、アカウントの管理、パスワードの再設定のため
  • 登録銘柄に関する重要ニュースの表示と通知のため
  • 登録銘柄に合わせた朝・大引けのレポートを作成し、表示・通知するため
  • 不具合の調査、不正利用の防止、お問い合わせへの対応のため

3. 外部サービスの利用

本アプリは、機能の提供のために次の外部サービスを利用します。

サービス用途送信・保存される情報
Supabase認証、データベース、サーバー処理第1項の情報
Expo（Expo Push Service）および Apple Push Notification serviceプッシュ通知の配信プッシュトークン、通知の本文
OpenAI（API）利用者向けレポートの文章作成登録銘柄の銘柄コード・銘柄名・業種、保有・監視の区分、保有数量、平均取得単価、現物・信用と売り・買いの区分、これらから計算した評価額や損益、ポートフォリオ全体の評価額・業種別の構成比率やTOPIXとの比較に加え、関連ニュースの見出し・要約や公開市場データ・分析。メールアドレス、ユーザーID、メモ、目標価格は送信しません。

OpenAI API へのリクエストでは応答をアプリケーション状態として保存しない設定（store: false）を使用しています。ただし、これは不正利用監視ログへの保存を無効にするものではありません。OpenAI の標準設定では、入力・出力が不正利用監視のため最長30日間保持される場合があります。詳しくはOpenAI API のデータ利用についてをご覧ください。

株価やニュースなど公開されている情報の取得先には、利用者の個人に関する情報を送信しません。

4. 第三者への提供

運営者は、法令に基づく場合を除き、利用者の同意なく個人に関する情報を第三者に提供しません。第3項の外部サービスへの送信は、本アプリの機能を提供するための委託として行うものです。

5. 保存期間と削除

取得した情報は、アカウントが存在する間保存します。利用者は本アプリの「設定」→「アカウントを削除」から、いつでもアカウントを削除できます。削除すると、本サービスで利用中のアカウントと関連データは削除され、元に戻すことはできません。外部サービスのバックアップやセキュリティログに含まれるコピーは、各事業者の保存期間に従って一定期間残る場合があります。詳しくはアカウントとデータの削除をご覧ください。
