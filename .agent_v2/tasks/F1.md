## 目的
共通AI基盤で生成・公開される朝刊と大引けを、既存アプリ画面と連動させる。
1. ホーム「今日のポイント」を共通市況レポート（朝刊/大引け）由来へ切り替える。
2. 「きょうの市況」から最新の朝刊・大引けと過去分を閲覧できるようにする。
既存デザイン維持。AI再生成なし。生成済み・公開済みの保存データのみ使用。

## 対象範囲
- `src/app/(tabs)/index.tsx`、`src/components/home/home-report-hero.tsx`、`src/app/market-report.tsx`、`src/lib/market-report-view.ts`、`src/lib/home-report-highlights.ts` と、必要な新規 lib / component / テスト。
- ホーム → 詳細の遷移（report_type / trading_date / 可能なら公開レポートID）。取得失敗時に別日へ誤フォールバックしないこと。
- 更新: 画面フォーカス復帰と手動更新のみ（ポーリング追加なし）。

## 安全制約
- 完成・公開されていないレポートは表示しない。端末時刻だけで朝刊/大引けの新旧を決めない。3項目未満のポイントを架空文で補完しない。
- 取得失敗時は空白にしない。保持してよいのは出所・日付が明確な最後の正常レポートのみで、古い場合は日付を明示。別日のレポートを当日として表示しない。
- 共通レポートを `PersonalizedReport` へ型キャストして流し込まない。専用の表示モデル／変換関数を使う。
- 新RPCを勝手に追加しない。不足は契約として F2 へ申し送る。
