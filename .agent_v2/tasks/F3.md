POSTONAで最初の「X手入力テキスト投稿1件」を、安全なローカルモック経路で完走させる。JWT主体確認 → 有効なPOSTONA利用権/T13 → 本人の確認済みXアカウント → credential取得port → 送信直前再確認 → X送信アダプター → 送信結果をdurable storeに保存/独立read-back。予約Cron・AI自動生成は後続。新しい投稿基盤を設計/複製せず既存X publisher、entitlement guards、F3 PR224/257/262/182を再利用。

- F3所有の小さな単発send orchestrator/adapterとserver-sideテストを追加できる。F1 app-owned routes/UI、G4 credentials/OAuth、F5 shared auth/RPC、旧x-test-post/共通legacy投稿、F4 Threadsを変更不可。変更対象が曖昧ならソース調査と契約報告だけに範囲を縮小。

Fail-before/pass-after, regression/mutation testsは重要境界を優先。
