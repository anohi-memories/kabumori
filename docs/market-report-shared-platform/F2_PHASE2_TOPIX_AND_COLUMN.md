## 3. ニュース選別（10/14 大引けのアクサスHD（3536）が通った原因と対策）

- 原因: 銘柄コードが無い行は、本文の「東証」「為替」などの言葉から付いた分類で「市場全体」扱いになっていた。また「AI」の分類はキーワードで付くため、AI と無関係な会社の重大ニュースも「業種に波及」として残っていた
- 対策
  - 銘柄コード（「（3536）」）、会社の形（HD・ホールディングス・株式会社）、開示の言葉（決算・業績・配当・自社株 など）で、行に銘柄コードが無くても企業ニュースと判定する。ただし、マクロの分類（金融政策・金利・米国市場・規制・地政学・エネルギーなど）が付いた記事は、決算の話でも市場全体のまま
  - 残す企業ニュースは2種類だけ: 大手（Core30 級・半導体の主力・メガバンク・自動車・エネルギー・商社など。銘柄コードの一覧）の high 以上、または半導体・エネルギーで重大（critical 以上）。海外の大手（エヌビディアなど）は名前で判定。最大2件
  - 「市場全体」の分類でも、相場への経路（分類か見出しの言葉: 原油・為替・金利・関税・物流・半導体など）が無い地政学・災害のニュースは最大2件。モデルには「市場との関係: 未確認」と渡し、主な材料にしないよう指示
  - 外したものは理由コード（`COMPANY_NOT_MARKET_WIDE`・`COMPANY_NEWS_CAP`・`BROAD_NO_MARKET_LINK_CAP`・`NEWS_TEXT_NOT_FACT_PASSED`・`NEWS_ITEM_CAP`）とニュースの id で `report_diagnostics` に記録
- 実データでの結果（リポジトリの過去の日）: 9/30 大引けの SBI 子会社どうしの統合（critical・AI の分類）が外れる。10/6 大引けは、相場との経路が無い地政学ニュース6件のうち、残るのは2件になる。日銀の決定・ホルムズ海峡・関税・半導体の協定などは残る

## 4. 文体（ゆめちゃんのコラム）

- ゆめちゃんは「ニュースを読み上げるアナウンサーではなく、自分の相場観を持った AI 評論家」と明記
- 流れ: 市場の事実 → 背景 → ゆめちゃんの解釈 → 今後の展開 → リスク。段落は前の段落を受けて書き出す
- 「私は〜と見ています」も含め、同じ言い回しを段落ごとに繰り返さない。語尾と文の長さに変化をつける
- 長さは必要以上に削らない。ただし中身の無い文で増やさない
- 朝刊・大引けの役割（朝: 今日どう動くと考えるか／大引け: 何が起きて、どう考えるか、答え合わせ、翌営業日）を明記
- X: 「📌 今日のポイント」→ 短い解説（導入と本文を1段落）→「🔮 ゆめちゃんの予想」。ゆめちゃんの行に「💬」の見出しを付けない。ゆめちゃんの行で「とみています」が2回続いていたのを直した

## 5. A案（理由が見当たらない値動き）

- 「理由は確認できません」と書く代わりに、意見と分かる言い方のゆめちゃんの見立てとして書く（例: 「材料ははっきりしませんが、私は円高が重しになったとみています」）
- 仮説も立てにくい日だけ、「はっきりした材料は見当たりません」を短く1回まで。その後にゆめちゃんの見方を続ける
- 守る線: 根拠ニュースの無い因果の断定は従来どおり取り除く。ニュースが理由を明記するときは事実（causal）のまま。見立ての中でも、作った数値・ニュースは取り除く
- 見立ての言い回し（ように見えます・気がします・のではないか・と読んでいます・〜ていそうです）を推測として扱うよう、ガードの正規表現を最小限だけ足した
- 本文の「理由・関係が無い」だけの文が2つ以上なら `REASON_ABSENCE_STATED:n` を記録（書き直しは起こさない。モデルの呼び出しは最大4回のまま）。本番の 10/2 朝刊は4回、10/6 大引けも複数回だった
