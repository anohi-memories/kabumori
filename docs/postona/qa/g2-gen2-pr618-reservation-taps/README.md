## 5. 持ち主ごとの依存と解除の条件

- **G1**: §4 の直し。G1 の flag を ON にするのは、G3 の入口の本番化と G4・G5 の条件の後。
- **G3**: 本来の入口（`postona-x-reservations`）は 503 のまま。手元の双子以外での確認は、G3 の出す順番の決定が要る。
- **G4**: 接続を切った後に開き直すと、最初の案内の「X を接続」に戻り「前回の接続が完了していません」と出る（R13。自分で切った場合には事実と違う）。ホームや一覧へ進めないので、**予定の残る予約があるときに見る・取り消す手段があるかは NOT_VERIFIED**（G1 と共同）。世代・接続の状態を読む口が決まれば、§3 の 20 を確かめられる。
- **G5**: 試験の利用者は直接入れたので、本物の登録の流れは通していない。
- **本番**: NO_GO。managed の DB・Auth・Edge、本物の SNS、有料 API、EAS には触れていない。
