## 2. 分類
- **表示の分離は守られている**（どの組み合わせでも、旧 A の案内・本文・操作・結果は B に出ず、B は A の試みを確認し直せず、A の同意は戻らない）。新しい境界違反は無い。
- 保存・記憶の残り（XI4・XI5）は既知 SM4-D と同じ種類。新しい指摘にはせず、修正の受入条件に足す:
  1. 退会の後片付けで、下書き（#470）と送信途中の記録・処理の中の記憶も消す。
  2. 退会の時点で**返事待ちの送信**がある場合、後から届く答えがその人の記録を作り直さない（XI5）。サーバーが投稿中の退会を断るなら XI6 の形になる（サーバーの判断は NOT_VERIFIED）。
- 既知のまま: G2-SN5・RK3・UC1（文言）、SM2・SM3R-T・SM4・SM4-D（保存）。実 Auth・実際の退会・実 X・サーバーの投稿中の退会の扱いは NOT_VERIFIED。本番 NO_GO。
