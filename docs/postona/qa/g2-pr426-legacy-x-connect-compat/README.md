## 1. 6件が #426 で止まる原因
`#426` の hook は、(1) `@/domain/recovery-binding` を読み込み（`sessionIdOf`）、(2) 開始時・交換の直前・成功の表示の直前に `supabase.auth.getSession()` で今のセッションを読み、(3) `session_id` で同じ人・同じセッションかを確かめる。#419・#425 の準備部分は (1) を持たない（読み込み一覧に無いと止める作り）ため、hook を読み込んだ時点で `unexpected import @/domain/recovery-binding` で止まる。(1) を足しても (2) が無いと、開始時に「今のセッションが無い」となり、ブラウザーも開かずに `session_changed` で止まる。どちらも**準備部分の不足**で、製品の動きの結果ではない。

記録: `originals-419-425-on-pr426.log`（20件中 14 通過・6 失敗。6 件とも `unexpected import @/domain/recovery-binding`。ログインの戻りの試験 14 件は通過）。
