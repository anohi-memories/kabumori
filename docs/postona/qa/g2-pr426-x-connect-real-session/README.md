## 1. G4 の試験との差
G4 の `x-connect-owner-session.test.mjs`（10件）は、getSession を**合成の値**で差し替えて、同じ範囲（B のログイン、ログアウト、A→B→A、同じセッションの token 更新、交換中の変化、読めないセッション、開始時の不一致、取り消し、やり直し、記録に出さない）を確かめている。本試験はそれを作り直さず、**本物の SDK の動き**で次を足した:
- getSession が**期限切れの token を自分で更新する**場合（更新で session_id が保たれること、交換に新しい token が使われること）
- 更新が**失敗する**場合（別の端末で「すべてログアウト」）
- 本物の signInWithPassword / signOut / updateUser による切り替え（合成ではなく SDK の保存と出来事を通る）
- 交換の**最中**の変化を、ログアウト・同じ人の新しいセッション・同じセッションの更新まで広げた
- 回復中のセッション（合言葉の変更）
- X での拒否・サーバーの期限切れの答え
