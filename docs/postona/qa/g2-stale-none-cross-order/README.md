## 4. 新しく見つかったこと（候補 #427 上、G1 へ一度だけ）
**G2-SN5（P3、表示のみ、担当 G1、候補 #427 上）**: 送信の前に読み込みを終えていた画面 B が新しい ID を送ろうとして壁に止められると、B には「送信は受け付けられませんでした」「サーバーは何も記録していません。本文は残してあります。」「コード: LOCAL_UNRESOLVED_ATTEMPT」「編集に戻る」だけが出る。**前の試みが X に投稿された可能性**も、「Xで確認しました」の操作も出ない。「編集に戻る」で同じ新規送信がまた出せて、また止められる（要求は出ない＝安全）。
- 再現: 同じ人の画面 A と B を開く（B は読み込みを終える）→ A で送信 → 「結果不明」→ B で同じ本文を確認・同意・送信。
- 期待: 壁が `LOCAL_UNRESOLVED_ATTEMPT` で止めたら、B は共有の未解決の試み（本文つき）を表示し、同じ ID の確認し直しと「Xで確認しました」を出す（A と同じ画面にする）。「サーバーは何も記録していません」は、前の試みについては本当とは限らないので出さない。
