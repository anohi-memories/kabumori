## 4. 新しく見つかったこと（G1 へ一度だけ）
**G2-RK3（P3、表示のみ、担当 G1、#435 上）**: 古い画面の再確認が「送信中」（`LOCAL_SEND_IN_PROGRESS`）で止まったときは、#435 の合わせ直しが働かず、その画面は**投稿済みの古い試み**を「通信できず、投稿されたかどうか分かりません」と表示し続け、再確認と「Xで確認しました」を出す。要求は出ない（安全）が、表示が事実と違い、しかもその「Xで確認しました」は H1 の P2（送信中の記録が消える）の入口になる。
- 再現: 同じ人の画面 A・B → A で送信（処理中）→ B を開く（処理中を表示）→ A で再確認（公開済み）→ A で「新しい投稿を作る」→ 新しい投稿を送信（返事待ち）→ B で古い再確認。
- 期待: 「送信中」で止めたときも、B を今のプロセスの状態（A の送信中の投稿を引き継ぐ「送信中」）に合わせ、古い試みの「Xで確認しました」を出さない。H1 の P2 の修正（「Xで確認しました」を送信中の予約・世代に参加させる）と合わせて直すのがよい。
