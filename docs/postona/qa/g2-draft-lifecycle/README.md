## 3. 新しい条件（G1/G5 へ一度だけ報告）

**G2-SM4-D（P3、owner G1 画面／G5 退会処理）退会しても下書きは消えず、その人は二度と読まないので、期限切れの判定もされず残り続ける。**
- 根拠（ソース）: `src/providers/auth-provider.tsx` の退会後の後片付けには「この端末のセッションと、その人ごとの状態を消す」という説明があるが、実際に消しているのは初回案内の記録（`onboardingStorageKey`）だけ。下書き（`postona.manual-publish.draft.v1:<人>`）も、送信途中の記録（`…unresolved.v1:<人>`、本文は無く要約値のみ）も消していない。下書きを消すコードは画面と下書き保存の中にしか無い（試験で走査）。
- 再現（模擬）: A が入力 → 退会（以後ログインしない）→ 30日後に B が使う → A の本文が端末に平文で残っている。
- 既知 SM4 との違い: SM4 は「同じ人が次に読むまで残る」。退会した人は次に読むことが無いので、**期限なしで残る**。
- 期待: 退会の後片付けで、その人の下書き（と送信途中の記録）も消す。あわせて、起動時に期限切れを掃除するか、画面の文言を実際に合わせる。
