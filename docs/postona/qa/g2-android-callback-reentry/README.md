## 3. 新しく見つかったこと（担当へ一度だけ）
**G2-CB5（P3、担当 X 接続 / G4）**: `use-x-connect.ts` の `connect` が開始時の `session` を閉じ込めて、戻りの交換にもその `access_token` を使う。ブラウザーが開いている間に別の人がログインすると、A の token で交換し、画面は B に A のアカウントの接続成功を表示する。
- 再現: A で X 接続を押す → ブラウザーが開いている間に B でログイン（模擬）→ 戻り。
- 期待: 戻ったときの人が開始時の人と違えば、交換を送らず、成功を表示しない（例: 開始時の user id を覚えて照合）。

**G2-CB1 / G2-CB3（観察、ログインの担当が確認）**: 設計どおりの可能性が高いため指摘にはしない。B のログイン中に A の古い戻りで A に入れ替わる点と、記憶を消す関数が使われていない点を記録する。
