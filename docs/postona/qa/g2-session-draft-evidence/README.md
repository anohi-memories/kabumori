## 2. 今回足した画面の負例（#380・#385・#411 と G1 の下書きの試験に無いもの）

| G2-DR2 | サーバーが送信を受け付けなかった（「本文は残してあります」）→「編集に戻る」で本文が戻り、再び保存され、同じセッションなら開き直しても戻る。新しいログインでは戻らない | PASS（文言と動きが一致） |
| G2-DR3 | 「下書きを消す」で保存がすぐ消え、開き直しても空 | PASS |
| G2-DR4 | 復元の読み込み中に打った本文が勝つ（古い下書きで上書きされず、保存されるのも新しい本文） | PASS |
| G2-DR5 | 復元の読み込み中は何も主張しない（結果の表示なし・送信できない）。復元後は編集の画面で、同意は戻らない | PASS |

| 負例 | 送信のときの消去を 2 か所とも外す → 送信後も下書きが残る（DR1 が検出）。明示の消去だけを外しても、保存の処理が消す（守りの重なり、計測） | 検出 |
