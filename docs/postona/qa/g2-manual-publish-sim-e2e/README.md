## 2. 新しい指摘（G1 へ一度だけ）
- **G2-E2E-1（P3、表示、持ち主 G1 のアプリの骨組み）**: 手入力で X に投稿の画面（ほかに上の帯を出す画面も同じ作りと思われる）の左上の戻るボタンに、ルートのまとまりの名前「(tabs)」がそのまま表示される。
  - 再現: ホーム →「投稿を作成する」（S01 ほか全部の写真の左上）。
  - 原因の見込み（ソース）: `src/app/_layout.tsx` の `<Stack.Screen name="(tabs)" />` に題名が無く、戻る先の題名としてまとまりの名前が使われる。
  - 直し方の候補（提案のみ、G2 は変えない）: `(tabs)` に `options={{ title: 'ホーム' }}` を付けるか、上の帯を出す画面に `headerBackTitle` を付ける。
  - 送信・認可には関係しない。
- 観察（指摘にしない）: 結果の画面に「コード: UNRESOLVED_FROM_EARLIER_VISIT」「コード: BUSY」のように内部の英字のコードが出る（S14・S18）。今の設計どおりで安全には関係しない。日本語の説明に置き換えるかは G1 の判断。

## 3. 環境の制約と持ち主
- iOS 27 の標準ビルドは、場面の設定が無いため起動しない（既知 OPEN、ネイティブの設定の持ち主は未定）。今回は G2 の診断用の直しで動かした。製品として直すまで、利用者の端末の確認は NOT_VERIFIED。
- 画面の日本語キーボードでは「#」が打てないため、偽の送信の口は本文の言葉（simu／pend など）でも答えを選ぶようにした（仕掛けだけ）。
- データは本物のサーバーが無いので、偽データを「読み込み済み」として渡した（仕掛けだけ）。本物のデータの読み込み・権限は NOT_VERIFIED。
