## 2. 約束（試験の規則）
- R1 本当に受け付けられた投稿だけが「受け付けました／投稿しました」と言う。
- R2 結果がまだ決まっていない種類（pending・unconfirmed・uncertain・simulated）は「送信されていません／投稿されませんでした／何も記録していません」と言わない。
- R3 結果がまだ決まっていない種類は「分からない／可能性／処理中／証拠でもない」ことを伝え、新しい投稿の操作（「新しい投稿を作る」「編集に戻る」）を出さない。
- R4 プロセスがこの人の未解決の試みを持っている間は、どの画面も「何も記録していません」と言わず、新しい投稿の操作を出さない。
- R5 投稿済みと分かっている試みを「分からない／確認できない」と言わない。

## 4. 新しい指摘（G1 へ一度だけ）
**G2-UC1（P3、文言のみ、担当 G1、#450・#461 で同じ）**: 結果が pending（サーバーが要求を受け取り、処理中・混雑で結果が出ていない）のとき、見出しと上の帯が「まだ送信されていません」と断定する。要求はサーバーに届いており、このあと投稿される可能性がある（本文中の「処理中の可能性」「投稿済みとは扱いません」とも食い違う）。利用者が「送られていない」と受け取り、別の手段で同じ内容を出すおそれがある。送信の動き（同じ ID の確認し直し・新しい投稿を出さない）は正しい。
- 再現: 送信 → 送信の口が `pending` を返す → 結果画面。
- 期待: 「投稿の結果がまだ出ていません（処理中）」のように、送られていないとは言わない文言にする（本試験の負例3がその形で関門を通ることを確認）。
