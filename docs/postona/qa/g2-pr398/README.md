## 4. 新しく見つかったこと（G1 へ一度だけ）
**G2-SM3R（P3、担当 G1、印の選び方は G5）**
- 根拠: #398 で画面の区切りにセッションの印（`last_sign_in_at`）が入った。トークン更新で返る user の `last_sign_in_at` が変わると（同じ人が別の端末でログインした場合。既知 SM2 の仮定、模擬）、ログアウトもログインし直しも無いのに、開いている画面が作り直される。
- 再現（模擬）: 入力中／確認中／送信の返事待ちに、同じ人の `last_sign_in_at` だけが変わったセッションを渡す（`G2-SM3R`・`-C`・`-S`）。
- 影響: 入力中の文章がその場で消える（SM2 では「次に開いたときに消える」だったのが、開いている画面でも起きる）。送信の返事待ちでは、表示が実際と違い（「通信できず」）、同じ番号の2回目の要求を並行して出せる（2回投稿にはならない決まり）。
- 期待: 印を、トークン更新で変わらないセッションごとの値（#380 の提案どおり、アクセストークンの `session_id` など。G5 で確認）にする。少なくとも、送信の返事待ちの間は画面を作り直さない、または作り直した画面が「まだ返事待ち」と正しく表示し、送り直しを出さない。
