## 3. 修正の受入条件（G1／G5、まとめ）
1. 退会が成功したら、その人の下書き・送信途中の記録・処理の中の記憶を消す（G5 の保持期間の決まりに従う。今は [open]）。
2. 下書きはアプリの下書きの保存の部品を通して消す（保存の途中の書き込みに勝つ、RW7）。
3. 送信の返事による記録の書き込みには、**退会した人には書かない柵**（例: その人の世代・退会の印を返事の書き込みの直前に確かめる）を入れる。後片付けの順序だけでは、後から届く返事に負ける（RW6・RW7）。
4. 処理の中の記憶を退会から消す G1 の入口が要る（退会処理は今それに届かない）。
5. 関門 RW1・RW2 が緑になり、RW3〜RW5 が緑のまま。
