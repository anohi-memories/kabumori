## 4. 診断：ガードが止められない事実改変（未修正・PASS扱いにしない）
`REWRITE_1010` から作った次の2件は、現行ガードで `edited` になる。ガードは本番X投稿経路（x-test-post）と共有の `brand/ai_lab_voice_rewrite.ts` にあり、本TASKの変更範囲外のため**変更していない**。テストで「通る」ことを固定もしていない。

1. **決定→実施済み（言い換え動詞）**：「画面に出すことにした」→「画面に出した」。`decisionTenseOverclaims` は決めたことの動詞そのもの（表示する→表示した）の過去形しか見ず、`DECISION_PARAPHRASES` の言い換え動詞（出す・見せる）の過去形（出した・見せた）を見ていない。修正案: `retoldVerbs(verb)` の各動詞にも `pastForms` を適用する。
2. **可能性→発生**：「後から届くかもしれなかった」→「後から届いて別の画面に混ざった」。出典の「可能性があった」を実際に起きた出来事に変えているが、内容語（返事・画面・届く・混ざる）がすべて出典にあるため、新語・新マーカー検査に掛からない。修正案: 出典が「可能性」「〜かもしれない」で述べる出来事を、本文が断定の過去形で述べたら止める。

どちらも別TASK（ガード変更のレビュー付き）で扱う。
