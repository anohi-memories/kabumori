- 4.7 以降のモデルは新トークナイザで、同じ文章が**約30%多く**カウントされる（公式）。
- **Web 検索**: Claude API で **$10 / 1,000 回**＋通常のトークン費用。エラー時は課金なし。ツール型は `web_search_20250305` / `_20260209`（動的フィルタ）/ `_20260318`（応答包含の制御）。`allowed_domains` / `blocked_domains`（併用不可）、`max_uses`、`user_location` が使える。管理者が Console で無効化・ドメイン制限をしている場合は 400。
- **構造化出力**: `output_config.format`（`json_schema`）。Haiku 5.5 / Sonnet 5.5 / Opus 5.5 / Fable 5.1 が対応。**`minimum`/`maximum`/`maxItems`/`minLength` などは非対応（400）**。現行の本番スキーマ（`confidence` の 0〜1、`maxItems`）はこのままでは送れず、比較環境では制約を説明文へ移して送る（`src/schema.ts`）。
- **サンプリング**: 5.5 世代は `temperature` 等が送れない。→ 同じ入力でも結果は完全には再現しない。
- **強制 tool_choice 不可**（5.5 世代）。**5.5 世代は refusal（`stop_reason: "refusal"`）あり**。
- **レート制限（Start tier、モデルごと）**: Opus 5.5 / Sonnet 5.5 / Haiku 5.5 とも 1,000 RPM / 入力 2,000,000 TPM / 出力 400,000 TPM。キャッシュ読みは入力 TPM に数えない。月間支出上限は Start **$500**（Build $1,000、Scale $200,000）。上限到達時は 429（`enforced_spend_limit_reached`、`retry-after` なし）。
- **無料のエンドポイント**: `GET /v1/models`（能力一覧）と `POST /v1/messages/count_tokens`（トークン数。Web 検索などサーバーツールは数えられない。Start tier 5,000 RPM）。

## 2. クレジットの確認状況

**公式ドキュメントで確認できたこと**（https://platform.claude.com/docs/en/about-claude/api-credits-for-subscribers）:
- Max 5x は毎月 **$100**、Max 20x は $200 の Claude API クレジット。対象は Claude API / Managed Agents / Agent SDK / Playground。**Claude Code とアプリの追加利用は対象外**。
- Console の組織を1つ紐づけて受け取る（プランと組織は1対1、**紐づけ先は自分で変更できない**）。新規契約は7日後から受け取り可。
- 毎請求サイクル（年払いは毎月）に付与。**サイクル末で失効、繰り越しなし**。組織内の全キー・全 Workspace が同じ残高を使う。
- 使い切って購入残高もなければ API は**停止**（プラン側へは課金されない）。メッセージ: `Your credit balance is too low ...`。
- クレジットは Start tier 以上を保証（クレジットが $200 超なら Build 以上）。レート制限・月間支出上限の計算は変わらない。
- 案件ごとに使用額を区切るには **Workspace ごとの spend limit** を使う。

**この環境から確認できなかったこと（未確認）**:
- 実際の付与の有無・残高・失効日・紐づけ先組織、現在の usage tier、Workspace の上限、Web 検索が組織で有効か、組織から見えるモデル一覧。
  - 理由: Console は本人のログインが必要で、Chrome 拡張が接続されておらず、Keychain の探索は自動モードの判定で拒否された（秘密情報の探索）ため。
- 参考情報（検証していない）: 別担当（G2）の 10/9 の報告に、Anthropic キーで実呼び出しをして約 $1.25 を Max 5x のクレジットから消費した、との記載がある。付与が機能している可能性を示すが、残高そのものの確認ではない。

→ **「Max 契約だけで API が無料」とは断定しない**。本書の自己負担額は、クレジット 0 を基本とし、「$100 が確認できた場合」を別行で示す。

## 4. 比較環境（`tools/provider-compare/`）

- **本番プロンプトの再利用**: 本番の `requestImportantNewsJudgement` / `requestGenerationStep` / `breakingMarketRequestBody` に偽の `fetch` を渡して送信内容を捕捉し、プロバイダー非依存の形式へ変換。**プロンプトを複製しない**ため、本番が変わっても追従する。
- **プロバイダー**: OpenAI（Responses API）、Claude（公式 SDK `@anthropic-ai/sdk` 0.132.1、SDK の自動再試行は無効化しハーネス側の再試行・予算に一本化）、`recorded`（本番の保存結果の再生。OpenAI 側の再呼び出しを避ける）、`mock`。
- **データ**: 実際の過去ニュース 22 件（日銀、為替、地政学、北朝鮮、国内企業の重大事案、金融庁の行政処分、TDnet 決算・資本・ガバナンス、生成失敗 6 件、取りこぼし 1 件、対照 2 件）。連絡先・メール・電話は除去。
- **指標**: 重要度判定（一致率、見逃し、過大/過小）、本文（本文中の数字が原文にあるか、見出しの日付、社名の保持、本番の `localFactIssues` / `localVoiceIssues`）、Fact/Voice（本番の保存判定との一致）、検索（出典数、許可ドメイン率、記事らしいURLの率）、API（トークン、検索回数、遅延、費用、再試行、timeout）。
- **安全装置**: 既定は dry-run（ネットワーク・キー不要、`--allow-net` なしで動く）。live は `PROVIDER_COMPARE_ALLOW_PAID=1`＋`--max-calls`＋`--max-usd`＋キーの全てが必要。全 HTTP 試行（再試行含む）を計上し、上限で停止。timeout は課金の可能性があるので見積り額を計上。キーは出力・結果に出さず、混入すると実行が例外で止まる。
- **無料の事前確認**: `probe_cli.ts`（モデル一覧の能力と `count_tokens`）。キーの有効性、Haiku 5.5 の Web 検索対応、各モデルの実トークン数（tokenizer 係数）を、課金なしで確認できる。
- **テスト**: 全 **159 件**成功（`deno test --no-config -A tools/provider-compare/src`）。型検査・lint も通過。

## 6. POSTONA との共用設計

`src/usage_dimensions.ts`（純関数・DB なし）に、provider / app / feature / model / month 別の集計と、月次クレジットの按分（Claude 分のみ対象、OpenAI は対象外、未使用分は失効として報告、アプリ間は使用額比例）を実装・テスト済み。現行の `ai_usage_events` には app 列がなく、書き込むのも重要ニュース Function のみ。実運用で持つには別途レビュー付きの変更が必要（今回は未実装）。実際の上限管理は **Console の Workspace spend limit**（アプリごとに Workspace と API キーを分ける）で行うのが公式の方法。

## 7. 「Claude へ移行する価値が高い工程」TOP3（**暫定**。実 API 比較は未実施）

1. **詳細重要度判定（gpt-6-sol 相当 → Sonnet 5.5 medium、必要なら Opus 5.5）**: OpenAI 支出の 66%、判断の影響が最大（取りこぼし）。単価が同じなので費用中立〜微増、クレジット確認後は実質 0。9/18 の日銀公式文書が `no_post` だった取りこぼし例を、判定の質で改善できるかが検証点。
2. **Web 検索（日次4イベント）**: 現行検索は出典の大半が媒体のマーケティング/ヘルプページで、候補化は 15 イベント中 2 件・重要 0 件。Claude の検索（ドメイン制御、動的フィルタ）で質が上がれば、少額（月 $1.5〜5）で日本固有領域の保険が強化できる。Haiku 5.5 が検索対応か要確認。
3. **本文生成（draft）**: 費用は小さい（OpenAI $0.5/月、Sonnet でも仮定 $12/月）が、Fact 失敗が生成の約16%、`generation_failed` が 24 件。数字・日付・留保表現の保持が良ければ公開率が上がる。G2 の別比較（市況レポート）では Opus が読みやすさで優位だったが費用は約3.5倍。

非推奨: Luna 相当の軽量工程（見出し一次判定、一次判定、Fact、Voice、アプリコピー）— 費用同等で合計も月数ドル。
